FREQUENTLY ASKED QUESTIONS

Good questions deserve clear answers.

A few things worth knowing before starting a software or infrastructure project.

Can you help with a project that is still just an idea?

Yes. Start by describing the business problem and what you want users to accomplish. A discovery discussion can help identify a realistic first version.

Do you only work on new applications?

No. We can discuss improvements to existing websites, deployment workflows, infrastructure, integrations, and maintenance needs.

Which technologies do you use?

Technology choices depend on the requirements. Common options include modern JavaScript frameworks, Python or Node.js backends, relational databases, containers, CI/CD tools, and cloud platforms.

How much will a project cost?

Pricing depends on scope, complexity, integrations, testing, hosting, and support. We prefer to understand the requirements before discussing an estimate.

How long does a project take?

Timelines depend on the size of the work, feedback cycles, access to required systems, and dependencies. A realistic schedule should be agreed after scoping.

Will we own our code and infrastructure?

Ownership, licensing, access, and handover should be explicitly defined in the project agreement. We recommend using client-controlled accounts where appropriate.

Do you offer ongoing support?

Maintenance and support can be discussed as a separate scope, including the systems covered, support hours, priorities, and response expectations.
